# Macro Indicators

Lern-Web-App zu den wichtigsten volkswirtschaftlichen Indikatoren aus dem Wirtschaftskalender (z. B. Forex Factory).

Sechs Kategorien: Inflation, Arbeitsmarkt, Wachstum und Konsum, Stimmung und Umfragen, Immobilien und Außenhandel, Zentralbank. Zu jedem Indikator: was er misst, womit er zusammenhängt und wie er auf den Leitzins wirkt. Nach jeder Kategorie folgt ein Test mit fünf Fragen.

## Nutzung

`index.html` im Browser öffnen. Keine Installation nötig, der Lernfortschritt wird lokal im Browser gespeichert.
